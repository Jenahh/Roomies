# Calendar icon atlas

`calendar-atlas.png` is the transparent PNG sprite sheet used by CalendarEventIcon in the event picker and calendar agenda. Native Image components render it on both phones and the web. Chore entries continue using the shared ChoreBadge.

Layout: four equal columns and two equal rows. Top row: dinner, meeting, study, game. Bottom row: groceries, household calendar, custom sparkles, bill.

Generated with the built-in image generation tool, referencing the existing laundry and dishes PNG chore icons. Original generated files were preserved. No external hosting is required.

Initial prompt: Create one transparent, regular 4x2 sprite atlas of pastel rounded 3D dinner utensils, meeting chat bubbles, study book, game controller, grocery basket, household calendar, custom sparkles and a bill receipt/coin. Match the existing chore icon family; no labels or text, consistent scale and padding.

Final refinement prompt:
Clean up this 4x2 pastel 3D calendar icon sprite atlas. Keep the SAME exact eight objects, SAME ordering and same equal cell alignment in a 2:1 image. Remove ALL square/rounded-square backing tiles, ALL glows, ALL shadows outside the actual objects, ALL colorful speckle/noise, ALL background pixels. Only the eight solid clean 3D objects should remain as sharp alpha cutouts floating on a perfectly transparent background. Each object centered in its cell with 18% transparent padding on every side, none touching cell boundaries. No text. Maintain the nice pastel glossy clay style. Output is one production sprite sheet PNG with genuine transparency, no mat, no floor, no shadow.
